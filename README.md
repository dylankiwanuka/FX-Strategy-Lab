# Final Year Project – Forex Trading Strategy Backtesting & Visualisation Tool

This project is an interactive educational tool for analysing and backtesting
technical trading strategies in the Forex market.

## Core Features
- Historical Forex data retrieval (Yahoo Finance)
- Technical indicators (SMA, EMA, RSI)
- Strategy-based signal generation
- Sequential backtesting engine
- Performance metrics (P/L, win rate, drawdown)
- Interactive Streamlit dashboard with visualisations

## Architecture
The system follows a modular layered architecture:

UI (Streamlit)  
→ Controller  
→ Strategy Engine  
→ Indicator Calculations  
→ Data Retrieval  

This structure improves maintainability, testability, and extensibility.
